# Surafel Jibruk - Portfolio (plain HTML / CSS / JS)

No installation and no build step. Double-click `index.html` to open it.
(Internet is needed for Bootstrap, icons and the Poppins font, which load from a CDN.)

```
portfolio-plain/
├── index.html          # page structure only
├── favicon.svg
├── css/                # variables, base, navbar, hero, sections, footer, responsive
├── js/                 # config, navbar, typing, reveal, scrollProgress, backToTop, contactForm, main
└── images/             # hero, about, netflix, evangadi-forum, chatgpt
```

## Publish
Upload the whole folder (index.html + css + js + images) to Netlify, GitHub Pages or any host.

## Edit
- Text/sections: `index.html`   - Colours: `css/variables.css`
- Contact form: `js/config.js` (email, or a Formspree URL to receive messages directly)
